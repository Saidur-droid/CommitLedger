# CommitLedger

**Canton-native settlement infrastructure for verified open-source work.**

CommitLedger turns validated GitHub contributions into programmable, auditable bounty settlements using Daml smart contracts and the Canton Ledger API.

> HackCanton Season 3 competition repository. The locked product, architecture, constraints, evidence policy, and submission gates live in [LOCKED_DECISIONS.md](LOCKED_DECISIONS.md).
