02 · CANTON TRUST LAYER

Why Canton is essential

Checking
  • Daml authorization: only the selected contributor submits work, only the verifier attests the merge, only the maintainer settles.
  • Evidence binding: repository, PR number, head SHA and base branch must match before verification.
  • Replay protection: settlement consumes the verified contract; the same work cannot settle twice.
  • Auditability: the final receipt carries bounty, PR, reward unit and evidence hash on ledger.
